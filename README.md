# Deja Vu 504 — Mission Control

Artist HQ for **Deja Vu 504**. Capture fans with a QR, own the phone numbers, and run follow-up, content, music, shows, and money from one phone-first app.

**Stop building followers you don't own. Build fans you can reach anytime.**

## What's in here

- Home dashboard with today's next move
- Capture fans (QR → inner circle join page)
- Fan CRM and follow-up texts
- Content machine and music rollouts
- Shows + Show Mode
- Brand / press kit, team, money

Prototype data is preloaded. My Team (the in-app advisor) uses xAI when `XAI_API_KEY` is set.

## Run

```bash
npm install
npm run dev
```

Auth is off. Demo data lives on the device.
